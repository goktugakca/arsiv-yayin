Who uses this tool

Arşiv Yayın Planlayıcı is a personal tool. Its only user is its owner, who runs it on their own computer to publish their own videos to their own channels. It has no other users, no accounts and no public interface.

YouTube API Services

This tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

With the owner's consent, given through Google's OAuth screen for each of the owner's channels, the tool requests these scopes:

  • youtube.upload: to upload the owner's videos.
  • youtube.force-ssl: to set a video's schedule, add it to the owner's playlist, read its public or private status, read the channel name, and post one comment on the owner's own video.

The tool does not read anyone else's videos, comments, subscribers, analytics or personal information.

What is stored, and where

  • OAuth access and refresh tokens are stored only on the owner's computer, in a folder that only the owner's user account can read.
  • The ID and link of each uploaded video are written to a local log on the same computer.
  • Nothing else from YouTube is stored. There is no server, database, analytics or advertising.

Sharing

No data is sold or shared with third parties. The tool talks only to Google (YouTube Data API) and Meta (Instagram Graph API), and only for the owner's own accounts. Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access and data

  • Access can be revoked at any time from Google security settings.
  • Deleting the local token file removes all stored credentials. Revoked or deleted tokens cannot be used again.

This website

This page is a static page hosted on GitHub Pages. It sets no cookies and collects no information.

Changes and contact

If this policy changes, the date above changes with it. Questions: github.com/goktugakca/arsiv-yayin/issues.
